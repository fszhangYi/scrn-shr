# 局域网键鼠

同一局域网里的两台 Windows 电脑之间转发键盘和鼠标。被控端显示地址和密码，控制端填好之后连接。两边都要手动打开，程序不会开机自启。

这一版只做键盘和鼠标。画面、文件传输和剪贴板不在这里。

## 怎么用

1. 被控端双击 `启动被控端.bat`。第一次运行会创建虚拟环境并安装依赖，需要本机已有 Python 3。
2. 窗口里会列出局域网地址、端口和控制密码。把这三项告诉控制端。关闭窗口后程序留在右下角托盘，退出请选“停止并退出”。
3. 控制端双击 `启动控制端.bat`，填入对方 IP、端口和密码，再点连接。
4. 连接后本机光标锁在控制窗口里，键盘和鼠标发给对方。`Esc` 释放光标，`Ctrl+Alt+Q` 断开。

不要把地址填成自己这台电脑，否则键鼠会自己带动自己。

如果控制端连不上，在被控端第一次弹出的防火墙提示里选择允许专用网络。

## 权限和做不到的事

以当前登录用户运行即可，不需要管理员，也不安装驱动。普通窗口可以操作。UAC 提示、Ctrl+Alt+Del 和锁屏在安全桌面上，普通程序的模拟输入到不了。已经“以管理员身份运行”的窗口有时也会丢掉低权限进程送来的输入。

## 会留下的痕迹

程序是可见的：任务管理器里有进程，窗口或托盘图标在，磁盘上有这些文件。被控端监听一个局域网端口。若在防火墙提示里点了允许，系统会留下一条入站规则。

密码只显示在被控端窗口里，不写入文件。程序不注册系统服务，不写入开机启动项。关掉并删掉目录之后，除了那条防火墙规则，没有别的入口。
